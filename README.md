**Coral City Heat** — an original open-world crime game set in Coral City, state of Marisol, at golden hour. Play as Paloma Reyes (the driver) and Dario Venn (the trigger), Tab-switchable, across five districts — Coral Beach, Downtown, Port Azahar, Las Ciénagas and Isla Verde — with traffic, pedestrians, a Marisol Sheriff pursuit system (patrol dispatch, Condor helicopter, roadblocks), a recruited crew with hotkey abilities (Pilar, Uncle Mateo, Juno), a five-mission story arc, weapon hotbar, GPS minimap, the Dockside Customs garage with tuning and save slots, and a full pause map with career stats. Built with Three.js, fully offline, no build step.

## Run it

```sh
node serve.ts                            # serves the game locally on port 8901
MAKEFUN_OUTPUT_DIR=out node main.ts      # builds the make.fun hand-in (game + screenshots + dossier)
```

Open the served page in desktop Chrome: WASD drive/walk · E enter car · SHIFT sprint · SPACE handbrake · TAB switch character · Q wheel · M map · mouse aim, click shoot.
